# Health Track

A modern healthcare and wellness tracking website designed with a clean UI and responsive experience.

🌐 Live Website:
https://health-track-theta.vercel.app/

---

## ✨ Features

* Modern Responsive Design
* Health & Wellness Interface
* Clean User Experience
* Mobile Friendly Layout
* Interactive Sections
* Fast Loading Website

---

## 🛠 Technologies Used
Frontend: NextJS, Typescript, Tailwind CSS, Javascript Backend: NodeJS (ExpressJS), Python Hosting: AWS (EC2) Database: MongoDB API: Mapbox, Weather API, Payment Gateway (Razor Pay), Google translator. AI: Custom itinerary generator (integration with LLM for chatbot guide)

---

## 📖 About The Project

Health Track is a modern web project focused on creating an elegant healthcare-themed user interface with smooth responsiveness and accessibility across devices.
